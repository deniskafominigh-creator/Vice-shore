# VICE SHORE

3D-игра от третьего лица в стиле GTA 6: вилла у моря, ремонт и баскетбол.
Готовы задачи **1–13**: меню, дом и остров, интерьер, ходьба от третьего лица,
миссия «покрась стену», миссия «два гола в кольцо», озвучка героя с субтитрами,
аудит сцены, мобильное управление и полный экран, настройки интерфейса и субтитров,
а также большой остров (156 × 116 м) с шестью домами, улицей, тысячей объектов декора,
травой и реалистичной водой.
Главный герой — **модель заказчика** (`src/assets/characters/character_rigged.glb`):
53 кости, рабочие пальцы, клипы Idle / Walk / Run / Paint / Hold / Throw (см. `docs/PROGRESS.md`).

## Запуск — одна кнопка

**Windows:** двойной щелчок по `start.bat`
**macOS / Linux:** `./start.sh`

Оба скрипта при первом запуске сами установят зависимости и поднимут игру в браузере.

Вручную:

```bash
npm install
npm run dev        # http://localhost:5173
```

## Готовая сборка (без сервера и без интернета)

```bash
npm run build      # → dist/index.html (один файл, всё внутри)
```

`dist/index.html` (≈11,6 МБ — внутри модель героя и реплики) открывается двойным щелчком
в любом современном браузере; сервер и интернет не нужны.

## Аудит сцены (задача 10)

`npm run audit:scene` — сам поднимает dev-сервер, проверяет сцену на мерцание (z-fighting), наложения, висящие предметы, осиротевшие коллизии и дубликаты, меряет бюджет кадра, проходит 6 маршрутов пешком и делает облёт по 20 точкам.

Итог последнего прогона: **0 конфликтов**, 2 704 исключения с причинами (листва, подушки, штакетник, кольцо на опоре, камни у воды, стыки конструктора посёлка и пучки травы), draw calls **462 → 221**, отчёт — `docs/AUDIT_SCENE.md`.

## Управление на телефоне и полный экран (задача 11)

Игра сама определяет устройство: на телефоне и планшете включается сенсорная схема, на компьютере — мышь и клавиатура. Схему можно зафиксировать в настройках («Управление»: Авто / Мышь / Сенсор).

- **Стик** слева — идти; довёл до упора — бег.
- **ПРЫЖОК** — круглая кнопка над «Действием» (в режиме покраски скрыта). Рядом с мячом
  удержание этой кнопки заряжает удар — как `Space` на клавиатуре, полоска силы видна на экране.
- **Свайп** по экрану — обзор; **щипок** двумя пальцами — приближение.
- **Держать** — это ЛКМ: вести валик по стене, замах и бросок мяча.
- **Ⓔ** — действие: взять предмет, начать красить, отойти.
- **II** — пауза. В режиме покраски добавляются **‹**, **МАКНУТЬ**, **›**.

Полноэкранный режим — переключатель в настройках (на iPhone Safari системно недоступен, там игра ставится на экран «Домой»).

Проверка: `npm run verify:touch` (телефон и компьютер в Playwright + собранный файл).

## Настройки интерфейса (задача 12)

В «Настройках» есть группа **Интерфейс**: можно по отдельности скрыть подсказки управления, подсказки действий и плашку задач с прогрессом — экран становится чистым, игра при этом идёт как обычно.

Группа **Субтитры**: 4 шрифта (по умолчанию «Кинематограф» — Playfair Display с засечками) и 4 фона плашки («Плёнка» по умолчанию, «Стекло», «Панель», «Без фона»). Все 16 сочетаний — на кадрах `docs/subtitle-shots/`.

Проверка: `npm run verify:ui`.

## Графика

ACES-тонмаппинг с экспозицией 1.2, sRGB, мягкие тени (`PCFSoftShadowMap`) и пост-обработка
`EffectComposer`: свечение ярких мест (UnrealBloom), Ambient Occlusion (SSAO) в стыках и под
персонажем, сглаживание SMAA; дальние дома и трибуны растворяются в дымке в цвет неба.

Цепочка собирается под пресет качества: **низкое** — прямой рендер без проходов (мобильные),
**среднее** — bloom + SMAA, **высокое** — плюс SSAO в половину разрешения и тени 4096. Если
средний FPS падает ниже 42, SSAO снимается на ходу. Метрики кадра — `F3` в игре (FPS, draw calls,
треугольники, строка `post`).

## Реплики героя

24 фразы в `src/data/dialogues.json`; у каждой есть `place` (`any` / `villa` / `court` / `stadium`),
поэтому «краска сохнет» не звучит на стадионе, а «вот она, арена» — у виллы. Idle-фраз ровно
три и они универсальные; на гол в футболе — три варианта по кругу. Все 24 фразы озвучены одним
тембром (светлый, бодрый), субтитры остаются страховкой, если файл не загрузился. Проверка набора
и звука: `npm run check:voice`.

## Остров и вода (задача 13)

Остров вырос с 64 × 46 до **156 × 116 м**. На нём шесть домов: старая вилла с интерьером и миссиями
в центре и пять новых вокруг (`src/world/island/Town.ts`), улица с фонарями, скамейками и клумбами,
дорожки от каждого дома к улице, 1 573 предмета декора и 9 000 пучков травы (один InstancedMesh
с ветром в вершинном шейдере).

Вода (`src/world/Sea.ts`) — семь волн Герстнера с аналитической нормалью, отражение неба, GGX-блик
с искрами, мель и пена прибоя по эллипсу острова, дымка горизонта. Тени едут за игроком
(`extent` 46 м), поэтому на всей карте они остаются резкими.

Кадры: `docs/world-shots/` (остров целиком, берег, искры на воде, улица, дом с бассейном).

## Стадион (задача 16)

Улица заканчивается у **«Вайс Шор Арены»** (`src/world/island/Stadium.ts`): чаша 43 × 29 м в
северо-восточном углу острова, поле 32 × 18 м с разметкой, пять рядов трибун и 980 пустых
сидений, ворота 6 × 2,2 м с сеткой, четыре мачты прожекторов и табло 8 × 3 м на мачтах над
северной трибуной. Ко входу ведёт аллея с бордюром, на площади — касса с тремя окнами (билеты
необязательны), вывеска «ВХОД» и три турникета в проёме восточной трибуны.

У кассы стоит живой кассир (модель героя, копия скелета, свой голос): `E` — поговорить,
`1…6` — вопросы про запись на матч, чужие матчи, команды и билет. Заявку он принимает в
Viced Boys («пока что без игроков»), билет продаёт один раз.

Вход — только через турникеты: проём закрыт металлом, по краям и между турникетами зашивы с
коллизиями, сверху навес с вывеской «ВХОД». Трибуны — 980 кресел (подушка, спинка, боковины,
ножка), все пустые.

Мяч (`src/game/Football.ts`) живёт на центре поля: его можно вести ногами, а `Space` рядом с ним
заряжает удар — 0,9 с до 100 %, полоска силы в интерфейсе, удар на отпускании (5,5…19 м/с).
Голы считаются по линиям ворот и сразу уходят на табло; вне матча на табло нейтральные 0:0.
Прыжок анимирован поверх клипов модели (`setJump`): клипа Jump в GLB нет, поза строится по
геометрии скелета — колени поджимаются, руки идут вверх, после касания короткий присед.
