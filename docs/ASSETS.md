# ASSETS — реестр ассетов и лицензии

Правило проекта: **никаких внешних CDN**. Все ассеты либо лежат в репозитории, либо генерируются кодом.
Каждый новый файл добавляется сюда с источником и лицензией (GOAL.md §6.1).
