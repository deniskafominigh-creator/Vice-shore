Маршрут — это 6–9 секунд ходьбы при зажатом направлении; каждый начинается из одной точки (старт у калитки). «Застревание» — остановка при зажатом направлении дольше 0.5 с. Если игрок при этом касается препятствия, остановка штатная (стена, забор, мебель) — важно, что «без стены» везде 0 кадров: значит ни зацепов, ни проваливаний нет.
